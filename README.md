# UCloud Cleaner

批量清理 UCloud 项目资源的工具。

Web 版基于 Flask，前端纯 HTML/CSS/JS，浏览器打开即用，支持 macOS / Windows / Linux 跨平台，所有计算在本地完成，数据不上传第三方服务器。

## 一、使用说明

### 1. 环境准备

1. 确保电脑已安装 Python 3（macOS 自带，终端输入 `python3 --version` 有输出即可）
2. 打开终端，进入项目文件夹：
   ```bash
   cd UCloudCleaner
   ```
3. 安装依赖（首次使用只需执行一次）：
   ```bash
   pip3 install ucloud-sdk-python3 flask
   ```

### 2. 启动 Web 服务

在终端执行：
```bash
python3 -m web.app
```

看到如下输出即启动成功：
```
UCloud Cleaner 已启动
本地访问: http://127.0.0.1:8080
按 Ctrl+C 退出
```

打开浏览器，访问 `http://127.0.0.1:8080` 即可使用。

> **停止服务**：回到终端，按 `Ctrl + C` 即可。

### 3. 使用步骤

#### 第 1 步：添加并选择账号
在左侧「任务配置」面板：
1. 点击「账号」旁的「**管理账号**」按钮
2. 点击「**新增账号**」，填写（带红色 `*` 的为必填项）：
   - **账号名称**：自定义名称
   - **环境地址**：下拉选择「正式环境」或「测试环境」（会自动带出对应 API 地址）
   - **公钥**：UCloud API 公钥（Public Key）
   - **私钥**：UCloud API 私钥（Private Key）
3. 点击「**保存账号**」
4. 在「账号」下拉框选中刚添加的账号，系统会自动加载该环境的区域列表

#### 第 2 步：获取并选择项目
点击「**获取项目**」按钮，拉取当前选中账号下的所有项目，然后在「项目」区域勾选要清理的项目（支持「全选」「取消选择」）。

#### 第 3 步：选择区域
在「区域」区域勾选要清理的可用区（支持「全选」「取消选择」）。

- 区域为可用区粒度，按名称升序展示，例如「香港可用区A(hk-01)」
- 右上角搜索框可按名称过滤，有内容时点右侧 × 可清除
- 切换账号后区域列表会自动刷新

#### 第 4 步：选择资源类型
在「资源类型」区域勾选要删除的资源，支持「全选」「取消选择」。

资源会按以下固定顺序删除（资源之间有依赖关系，顺序不可更改）：
```
UHost → UDisk → NATGW → UNI → ALB → NLB → EIP → UGN → UWAN → SecurityGroup → ACL → Subnet → VPC
```

#### 第 5 步：开始清理
点击「**开始清理**」按钮。右侧「运行日志」区域会实时显示删除进度：
- 绿色 = 正常 INFO
- 黄色 = 警告 WARNING
- 红色 = 错误 ERROR（失败会跳过，继续清理下一个）

右上角「队列」徽章显示当前排队任务数（含正在运行的）。

#### 第 6 步：停止或等待完成
- 任务运行中可点击「**停止**」按钮中断
- 任务结束后自动进入「历史」列表，可查看最终状态（成功 / 失败 / 已停止）

### 4. 安全说明

- **账号凭证保存在本地**：公私钥持久化到 `web/accounts.json`（已加入 `.gitignore`，不会提交到版本库），仅本机使用
- **私钥不写入浏览器**：不写入浏览器 localStorage；任务执行期间的内存副本在任务结束后立即擦除
- **API 响应脱敏**：接口返回中不包含 `private_key`，`public_key` 仅显示前 4 位
- **默认仅本机访问**：服务监听 `127.0.0.1`，除非手动修改 `web/config.json` 中的 `host`

### 5. 常见问题

**Q：启动时报 `Port 8080 is in use`？**  
A：8080 端口被其他程序占用。编辑 `web/config.json`，将 `port` 改为 8081 等其他端口即可。

**Q：切换账号后项目列表没变化？**  
A：切换账号后需要重新点击「获取项目」按钮拉取对应账号的项目。

**Q：日志区没有输出？**  
A：先确认任务状态为「running」；若仍无日志，按 F12 打开浏览器开发者工具查看 Console 是否有红色报错。

## 二、维护区域列表

编辑以下 JSON 文件可增加/删除可用区：

- `region/region.json` — 正式环境可用区
- `region/region_test.json` — 测试环境可用区

格式（键为「中文可用区名(代码)」）：
```json
{
  "香港可用区A(hk-01)": { "Region": "hk", "Zone": "hk-01" }
}
```

> 完整映射表可在 `region/zone-prod.json`、`region/zone-pre.json` 查看（本地文件，未纳入版本库）。修改 `region.json` / `region_test.json` 后 Web 版即时生效。
